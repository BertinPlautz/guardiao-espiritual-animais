📦 Arquivos de Configuração do Vercel

Baixe e adicione estes arquivos na pasta do seu projeto

📋 Instruções Rápidas: Para cada arquivo abaixo:
  1. Clique no botão "📋 Copiar Conteúdo"
  2. Abra o Bloco de Notas (ou editor de texto)
  3. Cole o conteúdo (Ctrl+V)
  4. Salve com o nome exato indicado
  5. Coloque na pasta do projeto

📄 1. vercel.json

Para que serve: Configuração principal do Vercel (headers, rotas, CORS) 

{
  "version": 2,
  "builds": [
    {
      "src": "**/*",
      "use": "@vercel/static"
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/$1"
    }
  ],
  "headers": [
    {
      "source": "/(.*)",
      "headers": [
        {
          "key": "Access-Control-Allow-Origin",
          "value": "*"
        },
        {
          "key": "Access-Control-Allow-Methods",
          "value": "GET, POST, PUT, DELETE, OPTIONS"
        },
        {
          "key": "Access-Control-Allow-Headers",
          "value": "Content-Type, Authorization"
        },
        {
          "key": "X-Content-Type-Options",
          "value": "nosniff"
        },
        {
          "key": "X-Frame-Options",
          "value": "SAMEORIGIN"
        },
        {
          "key": "X-XSS-Protection",
          "value": "1; mode=block"
        }
      ]
    }
  ],
  "rewrites": [
    {
      "source": "/",
      "destination": "/index.html"
    }
  ]
}

📄 2. robots.txt

Para que serve: Permite que Google, WhatsApp, Facebook indexem seu site 

# Robots.txt - O Guardião Espiritual dos Animais
# Permitir todos os crawlers

User-agent: *
Allow: /

# Crawlers específicos importantes
User-agent: Googlebot
Allow: /

User-agent: Googlebot-Image
Allow: /

User-agent: Bingbot
Allow: /

User-agent: facebookexternalhit
Allow: /

User-agent: WhatsApp
Allow: /

User-agent: Twitterbot
Allow: /

User-agent: LinkedInBot
Allow: /

# Sitemap
Sitemap: https://www.simbaspet.com.br/sitemap.xml

# Crawler-delay (evitar bloqueios por rate limiting)
Crawl-delay: 1

📄 3. sitemap.xml

Para que serve: Mapa do site para Google e outros buscadores 

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  
  <!-- Página Principal -->
  <url>
    <loc>https://www.simbaspet.com.br/</loc>
    <lastmod>2026-01-11</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  
  <!-- Página de Livros -->
  <url>
    <loc>https://www.simbaspet.com.br/livros.html</loc>
    <lastmod>2026-01-11</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
  
</urlset>

📄 4. .vercelignore

Para que serve: Arquivos que o Vercel deve ignorar no deploy 

# Arquivos que o Vercel deve ignorar

# Documentação
README.md
GUIA-*.md
COPY-*.md
OTIMIZACAO-*.md
INDEX.md
CONFERENCIA-*.md

# Testes
teste-analytics.html
BAIXAR-ARQUIVOS-VERCEL.html
exportar-projeto.html

# Sistema
.DS_Store
Thumbs.db
*.log

✅ Como Adicionar os Arquivos na Pasta do Projeto

  1. Baixe todos os 4 arquivos usando os botões "💾 Baixar" acima
  2. Abra a pasta onde você baixou os arquivos do projeto do Genspark
  3. Mova os 4 arquivos baixados para DENTRO da pasta do projeto (na raiz, junto com index.html)
  4. Estrutura final deve ficar assim:
📁 guardiao-espiritual-animais/
├── 📄 index.html
├── 📄 livros.html
├── 📄 vercel.json          ← NOVO
├── 📄 robots.txt           ← NOVO
├── 📄 sitemap.xml          ← NOVO
├── 📄 .vercelignore        ← NOVO
├── 📁 css/
│   └── 📄 style.css
├── 📁 js/
│   └── 📄 script.js
└── 📁 images/
    ├── 🖼️ mockup.png
    ├── 🖼️ autora.png
    ├── 🖼️ bonus1.png
    ├── 🖼️ bonus2.png
    └── 🖼️ livro1-5.jpg...
🎉 Pronto! Depois de adicionar os 4 arquivos na pasta do projeto, você pode:
  • ✅ Fazer o deploy no Vercel
  • ✅ Arrastar a pasta inteira para o Vercel
  • ✅ Fazer upload via GitHub
