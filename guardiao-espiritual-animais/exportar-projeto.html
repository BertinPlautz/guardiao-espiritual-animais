🚀 Migração para Vercel

Guia simplificado para migrar seu projeto

⚠️ Importante: Este é um guia de instrução. Os arquivos precisam ser baixados do painel do Genspark.

📋 PASSO 1: Criar conta no Vercel

1. Acesse: https://vercel.com

2. Clique em "Sign Up"

3. Escolha "Continue with GitHub" (recomendado)

4. Autorize a conexão

📦 PASSO 2: Preparar os arquivos

Você precisa dos seguintes arquivos do projeto:

📁 Arquivos Necessários:

📄 index.html - Página principal
📄 livros.html - Página de livros
📁 css/style.css - Estilos
📁 js/script.js - JavaScript
📁 images/ - Todas as imagens (10 arquivos)
⚙️ vercel.json - Configuração (já criado)
⚙️ robots.txt - SEO (já criado)
⚙️ sitemap.xml - SEO (já criado)

📤 PASSO 3: Fazer deploy no Vercel

Opção A - Upload Manual (Mais Fácil):

1. No Vercel, clique em "Add New Project"

2. Clique em "Import" ou arraste a pasta do projeto

3. Clique em "Deploy"

4. Aguarde 1-2 minutos


Opção B - Via GitHub (Mais Profissional):

1. Crie um repositório no GitHub

2. Faça upload dos arquivos

3. No Vercel, conecte o repositório

4. Clique em "Deploy"

🌐 PASSO 4: Conectar domínio simbaspet.com.br

1. No Vercel, vá em "Settings" → "Domains"

2. Adicione: www.simbaspet.com.br

3. O Vercel mostrará os DNS que você deve configurar

4. No Registro.br, adicione os DNS do Vercel

5. Aguarde 24-48h para propagação

✅ Benefícios do Vercel:
  • ✅ 100% Gratuito
  • ✅ Status Code 200 garantido (sem erro 405)
  • ✅ Google Analytics funciona perfeitamente
  • ✅ Preview em WhatsApp/Instagram/Facebook
  • ✅ SSL automático (HTTPS)
  • ✅ CDN global (site super rápido)
  • ✅ Deploy automático (atualizações instantâneas)
